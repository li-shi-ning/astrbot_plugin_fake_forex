# 虚拟外汇

QQ 官方群聊虚拟外汇交易插件。行情完全由插件随机生成，不接真实交易数据。

## 玩法规则

- 参考 `fx-simple` 的保证金 + 杠杆交易玩法。
- 股票：水母水产、预制菜赌场、辉叶股、真叶股、茵菲诺黄金、芋头股、卯月股、爱素矿产、千音集团、糯米文娱、长期素食、白毛兽业、睦缇斯暴力公司、咲夜航空。
- 全服共用一个虚假市场，所有群看到同一行情。
- 初始现金 $10,000，最低保证金 $10，默认杠杆 20x，最大 100x。
- 做多、做空均按买卖点差成交。
- 开仓和平仓各收 0.05% 名义仓位手续费。
- 大单按仓位/净值比例产生滑点，最高 1.5%。
- 每 30 分钟收取持仓费，做空额外收取借券费。
- 爆仓时额外收取 1% 名义仓位罚金。
- 持仓浮亏最高按保证金封顶显示，实际爆仓亏损不会超过保证金 + 手续费 + 罚金。
- 行情有随机新闻事件，可能瞬间跳空 5%-25%。
- 超级波动和新闻只造成一次性跳空，不再提供同方向持续趋势。
- 超级波动只造成一次性跳空，不再提供持续趋势。
- 波动率越高，该股票允许的最大杠杆越低。
- 亏损达到保证金的 80% 自动爆仓。
- 行情有低概率触发超级波动，价格可能永久偏离原价位。
- 贷款每 30 分钟按 3% 复利计息。
- 基础贷款额度 $200,000，每天额外增加 $200,000 额度。
- 可以出售器官换取现金，卖器官不影响交易和健康。
- 器官不会每天刷新；每种器官卖掉后处于已出售状态。
- 破产救济只影响现金和债务，不计入交易盈亏排行榜。
- 未成年退款：现金 <= 0 或净值 < 0 时可申请；清空负债、现金恢复初始，24 小时内不能购买股票和彩票；不影响器官、背包和排行榜。
- 破产申请每天最多 3 次，且现金 <= 0 或净值 < 0 时才能申请。
- 已出售的器官可以用相同价格买回，买回后可以再次出售。
- 可申请最高 $200,000 的贷款，每 30 分钟按 3% 复利计息。
- 行情每 30 秒推进一个 tick；每次命令时按真实经过时间补推进。
- 彩票与股票共用同一现金系统；票价 100，号码 1-100，基础奖池 200,000。
- 每张彩票向奖池注入 10,000（票价 100 × 100）。
- 奖池上限 1,000,000，达到上限后不再增加。
- 市场：玩家可以自定义上架商品和价格，每人最多 5 件；买卖只影响现金，不影响交易盈亏排行榜；背包保存已购买物品。
- 集市按钮布局：每行 3 个，共 4 行商品，第 5 行为上一页 / 页码 / 下一页。
- 买彩票立即开奖；中奖清空奖池，只保留基础奖池，未中则奖池累积。

## 命令

| 命令 | 说明 |
| --- | --- |
| `外汇菜单` / `外汇帮助` | 打开菜单和帮助 |
| `外汇行情` | 查看全部外汇对行情图 |
| `外汇查看 水母水产` | 查看指定股票 K 线图 |
| `外汇做多 水母水产 500 20` | 做多，保证金 $500，杠杆 20x |
| `外汇做空 水母水产 500 20` | 做空，保证金 $500，杠杆 20x |
| `外汇持仓` | 查看账户和持仓 |
| `外汇平仓 p1234567` | 平掉指定持仓 |
| `外汇全平` | 平掉全部持仓 |
| `外汇账户` | 查看账户图片 |
| `外汇设置 保证金 500` | 设置按钮默认保证金 |
| `外汇设置 杠杆 20` | 设置按钮默认杠杆 |
| `外汇借款 10000` | 申请贷款 |
| `外汇还款 5000` | 偿还贷款 |
| `外汇历史` | 查看最近平仓记录 |
| `彩票菜单` | 查看彩票奖池和规则 |
| `买彩票 88` | 购买数字 88 的彩票并立即开奖 |
| `彩票奖池` | 查看当前彩票奖池 |
| `彩票排行` | 查看全服累计中奖金额排行榜（含历史记录） |
| `市场菜单` / `集市` | 打开集市，查看商品列表 |
| `上架 空气 100` | 上架自定义商品 |
| `下架 3` | 下架自己的商品 |
| `购买 3` | 购买集市商品，放入背包 |
| `背包` | 查看自己买到的物品 |
| `外汇排行` | 查看群友交易盈亏排行榜 |
| `破产申请` | 每天一次，债务减半，现金恢复到 $10,000 |
| `未成年退款` | 清空负债、现金恢复初始，24 小时禁止购买股票和彩票 |
| `外汇器官` | 查看器官回收站 |
| `外汇卖器官 心脏` | 出售一个器官换取现金 |
| `外汇买器官 心脏` | 买回已出售的器官 |
| `外汇添加股票 NEWX 新股票 33.3` | 管理员添加自定义股票 |

## 按钮

- 菜单按钮：行情、账户、持仓、历史、借款、还款、帮助。
- 行情按钮：每只股票都可直接打开。
- 单个股票按钮：按账户当前默认保证金和杠杆直接做多或做空。
- 持仓按钮：每个持仓可单独平仓，也可一键全平。

## 数据

- 全局市场状态和每个群的玩家账户保存在插件数据目录 `fx_state.json`。
- 插件重启不丢行情和账户。
