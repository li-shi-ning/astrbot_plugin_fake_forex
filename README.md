# 虚拟外汇

QQ 官方群聊虚拟外汇交易插件。行情完全由插件随机生成，不接真实交易数据。

## 玩法规则

- 参考 `fx-simple` 的保证金 + 杠杆交易玩法。
- 股票：水母水产、预制菜赌场、辉叶股、真叶股、茵菲诺黄金、芋头股、卯月股、爱素矿产、千音集团、糯米文娱、长期素食、白毛兽业、睦缇斯暴力公司、咲夜航空。
- 全服共用一个虚假市场，所有群看到同一行情。
- 初始现金 $10,000，最低保证金 $10，默认杠杆 20x，最大 100x。
- 做多、做空均按买卖点差成交。
- 开仓和平仓各收 0.05% 名义仓位手续费。
- 大单按仓位/净值比例产生滑点，最高 1.5%。
- 每 30 分钟收取持仓费，做空额外收取借券费。
- 爆仓时额外收取 1% 名义仓位罚金。
- 行情有随机新闻事件，可能瞬间跳空 5%-25%。
- 波动率越高，该股票允许的最大杠杆越低。
- 亏损达到保证金的 80% 自动爆仓。
- 行情有低概率触发超级波动，价格可能永久偏离原价位。
- 贷款每 30 分钟按 3% 复利计息。
- 基础贷款额度 $200,000，每天额外增加 $200,000 额度。
- 可以出售器官换取现金，卖器官不影响交易和健康。
- 器官不会每天刷新；每种器官卖掉后处于已出售状态。
- 已出售的器官可以用相同价格买回，买回后可以再次出售。
- 可申请最高 $200,000 的贷款，每 30 分钟按 3% 复利计息。
- 行情每 30 秒推进一个 tick；每次命令时按真实经过时间补推进。

## 命令

| 命令 | 说明 |
| --- | --- |
| `外汇菜单` / `外汇帮助` | 打开菜单和帮助 |
| `外汇行情` | 查看全部外汇对行情图 |
| `外汇查看 水母水产` | 查看指定股票 K 线图 |
| `外汇做多 水母水产 500 20` | 做多，保证金 $500，杠杆 20x |
| `外汇做空 水母水产 500 20` | 做空，保证金 $500，杠杆 20x |
| `外汇持仓` | 查看账户和持仓 |
| `外汇平仓 p1234567` | 平掉指定持仓 |
| `外汇全平` | 平掉全部持仓 |
| `外汇账户` | 查看账户图片 |
| `外汇设置 保证金 500` | 设置按钮默认保证金 |
| `外汇设置 杠杆 20` | 设置按钮默认杠杆 |
| `外汇借款 10000` | 申请贷款 |
| `外汇还款 5000` | 偿还贷款 |
| `外汇历史` | 查看最近平仓记录 |
| `外汇排行` | 查看群友交易盈亏排行榜 |
| `外汇器官` | 查看器官回收站 |
| `外汇卖器官 心脏` | 出售一个器官换取现金 |
| `外汇买器官 心脏` | 买回已出售的器官 |
| `外汇添加股票 NEWX 新股票 33.3` | 管理员添加自定义股票 |

## 按钮

- 菜单按钮：行情、账户、持仓、历史、借款、还款、帮助。
- 行情按钮：每只股票都可直接打开。
- 单个股票按钮：按账户当前默认保证金和杠杆直接做多或做空。
- 持仓按钮：每个持仓可单独平仓，也可一键全平。

## 数据

- 全局市场状态和每个群的玩家账户保存在插件数据目录 `fx_state.json`。
- 插件重启不丢行情和账户。
